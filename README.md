# StatChanger

StatChanger is a web-based tool designed to visually represent the stat changes applied by different gear in the Nintendo Switch game *Mario Strikers: Battle League*. It provides a user-friendly interface to simulate the in-game effects of equipping various armor pieces, allowing players to easily understand how their character's stats are affected.

It is only a frontend project made in React to show quality in CSS and Frontend management and design

## Features

*   **Visual Stat Representation:** See clear visual changes to your character's stats as you select different gear.
*   **Intuitive UI:** Easy-to-use interface for selecting and comparing different gear combinations.
*   **Accurate Data:** Uses in-game data to ensure accurate stat representation.
*   **Gear Comparison:** Compare the stat changes between different gear sets side-by-side.
*   **Mobile-Friendly:** Designed to be accessible on various devices.
